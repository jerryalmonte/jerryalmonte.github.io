Privacy Policy

Claude Google Ads MCP · last updated 14 November 2026

What this app is

Claude Google Ads MCP is a private tool run by Jerry Almonte on his own computer. It connects Claude Code to the Google Ads accounts he manages so he can review performance and plan changes.

What data it accesses

With your permission, the app uses the Google Ads API (scope https://www.googleapis.com/auth/adwords) to read and, when you approve it, change data in Google Ads accounts you have access to: campaigns, keywords, ads, budgets, conversion settings and performance reports.

How the data is used

The data is used only to produce audits, reports and recommendations for the account owner, and to carry out changes the account owner approves. It is not sold, not used for advertising, and not shared with anyone except as needed to run the tool. Reports are processed by Anthropic's Claude AI service so it can analyse them.

Storage

Sign-in credentials are stored only on the owner's computer. Google Ads data is not kept on any server operated by this app.

Removing access

You can revoke the app's access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
